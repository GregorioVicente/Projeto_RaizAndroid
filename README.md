# Raiz para Android

Protótipo nativo em Kotlin e Jetpack Compose inspirado nas telas do arquivo Figma fornecido. O projeto inclui os fluxos de boas-vindas, início, cultivos, plantio, detalhe do cultivo, custos, colheita, feira, venda e resultados.

## Abrir

Abra a pasta `RaizAndroid` no Android Studio e aguarde a sincronização do Gradle. Depois, execute o app em um emulador ou dispositivo Android (API 24 ou superior).

Os botões principais navegam entre as telas e os formulários aceitam edição local. Integrações com banco de dados, câmera, microfone, notificações e sincronização ainda não fazem parte deste protótipo.
